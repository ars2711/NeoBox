Place your branding assets in this folder using these exact file names:

- logo.png               (main app logo used in navbar)
- favicon.png            (tab icon)
- favicon.ico            (tab icon fallback)
- apple-touch-icon.png   (recommended 192x192 PNG)
- logo-192.png           (PWA icon 192x192)
- logo-512.png           (PWA icon 512x512)
- og-image.png           (social preview image, recommended 1200x630 PNG)

Optional fallback files:
- og-image.svg

After replacing files, do a hard refresh (Ctrl+F5) so cached icons update.
